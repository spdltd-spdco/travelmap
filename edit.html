🗺️ TravelMap Builder

—
Draw regions with the tools on top of the map. Toggle Add marker then click the map to drop POIs. Everything auto-saves to this browser.

Google Maps API key

This tool runs entirely in your browser and needs your own key.

  1. Open the Google Cloud Console → Credentials and create an API key.
  2. Enable Maps JavaScript API and Places API for the project (billing must be on; there's a large free monthly tier).
  3. While testing from a local file, set the key's application restriction to None (referrer restrictions don't match file://). Lock it down later.

Stored only in this browser's localStorage. Clear it anytime with the API key button.
